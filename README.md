### Proyecto de tesis, construcción de un robot 4wd operado mediante IA
### Por: Francisco Nava Valencia | [Ciencias UNAM](mailto:francisconavavalencia@ciencias.unam.mx)

Repositorio de respaldo con miras a ser el principal a cerca del trabajo realizado para elaborar mi Tesis de un robot  4WD en el que se implementan modelos IA de YOLO compatibles con el chip HAILO.

---

## 🛠️ Herramientas y Tecnologías
* **Lenguajes:** `Python 3.x`
* **Entornos:** `VS Code`
* **Hardware en la mira:** Microcontroladores, Sensores de proximidad, Actuadores, camara.
* **Librerías clave:** `NumPy`, `Matplotlib`, `OpenCV`, `Gpiozero`.

## 📂 Estructura del Repositorio
| Carpeta / Archivo | Descripción |
| :--- | :--- |
| `scripts/` | Archivos `.py` listos para ejecución directa. |
  | `scripts/Vsion` | Archivos `.py` enfocados en tareas de visión.|
  | `scripts/Hardware` | Archivos `.py` enfocados en tareas de control de hardware (principalmente motores y servos).|
| `docs/` | Diagramas de conexiones y guías teóricas. |
| `README.md` | Guía principal del repositorio (este archivo). |
